# 시작하기 전에

개발자가 작성한 모든 코드는 컴퓨터 내부에서 명령어로 면환된다.
이번 절에서는 어떻게 명령어로 변환되는지 알아보자

# 고급 언어와 저급 언어

컴퓨터는 Javascript, Java, Python, C와 같은 고급 언어를 이해하지 못한다.
따라서, 이러한 고급 언어를 컴퓨터가 이해 가능한 **기계어** or **어셈블리어**와 같은 저급 언어로 변환해주어야 한다.

# 컴파일 언어와 인터프리터 언어

고급 언어를 저급 언어로 변환하는 방식은 두 가지

- 컴파일 방식
- 인터프리터 방식

각각의 방식을 사용하는 언어를 컴파일 언어, 인터프리터 언어 라고 한다.

## 컴파일 언어

- 컴파일 언어는 **컴파일러**를 통해 소스 코드를 컴파일 한다.
- 컴파일은 소스 코드에 문법적인 오류는 없는지, 실행 가능한지, 불필요한 코드는 없는지 따지는 과정이다.
- 컴파일의 결과는 **목적 코드**가 된다.
- 컴파일 과정 도중 에러를 발견하면 소스 코드 전체 실행이 불가능하다.

## 인터프리터 언어

- 인터프리터 언어는 **인터프리터**를 통해 소스 코드가 한 줄씩 저급 언어로 변환한다.
- 따라서 N번째 줄에 오류가 있어도, N-1번째 줄까지 실행 가능하다.

일반적으로 컴파일 언어가 인터프리터 언어보다 속도가 빠르다(컴파일 언어는 한 소스 코드 파일을 전부 변환하지만, 인터프리터는 한줄씩 모든 줄을 저급 언어로 변환 후 실행해야 함)

## + 여기서 잠깐: 컴파일 언어와 인터프리터 언어

컴파일 언어와 인터프리터 언어는 명확히 구분되지 않는다.

가령, Python 같은 인터프리터 언어도 컴파일을 하지 않는 것이 아니며, Java의 경우 컴파일과 인터프리트를 동시에 수행한다.
따라서, 고급 언어가 저급 언어로 변환되는 방식에 컴파일, 인터프리터 두 가지 방식이 있다~ 정도로 이해하자.

# 좀 더 알아보기

## 목적 파일 VS 실행 파일

목적 코드는 저급 언어니까 목적 파일이 실행 파일일까? 아니다.

목적 코드가 실행 파일이 되기 위해서는 **링킹**이라는 작업이 필요하다.
