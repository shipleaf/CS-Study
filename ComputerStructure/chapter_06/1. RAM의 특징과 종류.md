# RAM의 특징

RAM은 컴퓨터의 전원을 끄면 저장된 내용이 사라지는 **휘발성 저장 장치**이다.<br />
반면, 전원이 꺼져도 저장된 내용이 유지되는 저장 장치를 **비휘발성 저장 장치**라고 합니다. 하드 디스크나 SSD, CD-ROM, USB 메모리 등이 있죠

CPU는 보조기억장치에 직접 접근하지 못한다. 그래서 일반적으로 보조기억장치에는 '보관할 대상'을 저장하고, 주기억장치에는 '실행할 대상'을 저장한다.
실행시에 프로그램을 보조기억장치에서 RAM으로 복사하여 저장한 뒤 실행한다.

# RAM의 용량과 성능

RAM 용량이 적다면, RAM에 적재할 수 있는 크기가 부족하니 실행할 프로그램을 가져오는 일이 잦아 실행 시간이 길어진다.
반대로 용량이 무지막지하게 크다고 해서 성능이 비례해서 늘어나지는 않는다.

# RAM의 종류

## DRAM

적재된 데이터가 시간이 지나면 사라지고 변하는 RAM을 의미한다. DRAM은 데이터의 소멸을 막기 위해 일정 주기로 데이터를 재활성화(다시 저장)해야 한다.
이런 단점에도 불구하고 소비 전력이 낮고, 저렴하고, 집적도가 높아 대용량으로 설계하기가 용이하다.

## SRAM

DRAM과 달리 SRAM은 시간이 지나도 저장된 데이터가 사라지지 않는다. 따라서, 재활성화가 필요없기 때문에, 일반적으로 DRAM보다 빠르다.<br/>
이런 장점에도 불구하고, SRAM보다 DRAM이 더 많이 활용되는데, 이유는 SRAM이 집적도가 낮고, 소비 전력도 크며, 가격도 더 비싸다. SRAM은 '대용량으로 만들어질 필요는 없지만, 속도가 빨라야 하는 저장 장치', 가령 캐시 메모리에서 사용됩니다.

## SDRAM

CPU 클럭 신호와 동기화된 DRAM, CPU와 정보를 주고 받을 수 있다.

## DDR SDRAM

대역폭을 넓혀 속도를 빠르게 만든 SDRAM. 여기서 **대역폭**이란 '데이터를 주고받는 길의 너비'를 의미한다.<br />
**DDR SDRAM**은 한 클럭당 **SDR SDRAM(Single Data Rate SDRAM)**의 두 배의 데이터를 주고받는다.<br/>
DDR2 SDRAM은 DDR SDRAM보다 두 배, DDR3 SDRAM은 DDR2 SDRAM의 두 배의 대역폭을 가진다.
