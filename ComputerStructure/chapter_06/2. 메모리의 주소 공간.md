# 시작하기 전에

**물리 주소**는 메모리 하드웨어가 사용하는 주소, **논리 주소**는 CPU와 실행 중인 프로그램이 사용하는 주소이다.

# 물리 주소와 논리 주소

메모리에 저장된 정보는 시시각각 변하기 때문에, CPU와 응용 프로그램이 인지하고 있을 **논리 주소**가 필요하다.
논리 주소를 통해 응용 프로그램들은 같은 논리 메모리 주소를 가지게 될 수 있다.

다만, CPU와 메모리 하드웨어가 상호작용하려면 논리 주소와 물리 주소 간의 변환이 이루어져야 한다.
논리 주소와 물리 주소 간의 변환은 CPU와 주소 버스 사이에 위치한 **메모리 관리 장치(MMU: Memory Management Unit)**라는 하드웨어에 의해 수행된다.

MMU는 논리 주소에 베이스 레지스터(응용 프로그램의 물리 주소가 시작하는 위치) 값을 더하여 논리 주소를 물리 주소로 변환한다.

# 메모리 보호 기법

논리 주소 값의 연산이 잘못되어 할당된 물리 주소 바깥의 데이터의 접근하면 큰 문제가 발생한다. 이는 **한계 레지스터**라는 레지스터가 담당한다. **한계 레지스터**는 논리 주소의 최대 크기를 저장한다.

응응 프로그램의 물리 주소는 베이스 레지스터부터 베이스 레지스터 값에 한계 레지스터 값을 더한 범위를 넘지 않는다.
